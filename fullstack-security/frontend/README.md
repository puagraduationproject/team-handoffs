## Sending us a request

Put it in `requests/` named `FE-<number>-<short-name>.md` using `templates/request.md`, then ping us on WhatsApp or Discord.

Please include:

- Screens or flows affected
- All user-facing texts, including errors
- Error codes the API returns (see `shared/error-codes.md`)
- Designs or screenshots, if any

## Folders

- `requests/`: what other teams need from us
- `designs/`: our designs for the other teams to see, one folder per request (format in `designs/README.md`)
- `notes/`: our informal docs
